Course advice you can check. Every line.

Pathwise answers students' questions from the course catalog, the student handbook, and their own record. Every statement cites its source, and every quote is checked word for word in code before it is shown.

Asking as

Sources

Every statement in an answer links to a numbered source here, with the quoted passage highlighted.

Quotes are checked word for word against the source before they are shown. A statement without a verified quote is marked as unsupported.

How an answer is built

Claude writes the answer, but only from sources it is handed, and code decides what counts as supported.

Hybrid retrieval

Keyword search (BM25) and local embeddings, merged by rank fusion. Courses named in the question, by code, title, or abbreviation, are always included with their prerequisites.

Rules computed in code

Prerequisites, credit limits, overloads, probation, and timetable clashes are checked against the student's record. Each check names the handbook rule it applies.

Cited statements

Claude returns a list of statements. Each one cites a source by id with a short quote copied from it, or the question is declined as not covered.

Verified quotes

Every quote is located in its source text. Quotes that are not there are rejected, and a statement with no verified quote is shown as unsupported.

Answers

MetricScore

A small, fictional catalog, so treat these as a regression check rather than a benchmark. Quote checks catch invented quotes, not every wrong claim, which is why the set also tests answers against expected sources.

Use it from Claude

An MCP server exposes the advisor to Claude Desktop and Claude Code.

Tools

  • ask: a full answer with numbered sources and verified quotes
  • search_catalog, get_source: search and read catalog and handbook sources
  • check_course, check_plan: eligibility and plan checks with the rule behind each issue
  • student_progress, eligible_courses, list_students

Everything except ask runs locally with no model call.

Run it locally

git clone https://github.com/akshay-9640/pathwise
cd pathwise && uv sync
uv run pathwise          # web app
uv run pathwise-mcp      # MCP server
uv run pathwise-eval     # evaluation

The catalog, handbook, and students are fictional, made for this demo. The answers above were produced by the real app and are replayed unchanged from demo.json.
